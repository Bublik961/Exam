# Совместная подготовка к экзамену по Программированию (C++)

База знаний для подготовки к экзамену по языку C++.

## Распределение вопросов
- **Тенц Ангелина**:
  1. Числовые типы данных
  2. Списки и строки
  3. Сумма положительных чисел
- **Колесникова Софья**:
  4. Условный оператор
  5. Циклы
  6. Подсчёт подходящих элементов

## Структура папок
- `Answers/` - ответы на экзаменационные билеты.
- `Terms/` - единый словарь терминов.
- `Decisions/` - журналы ревью и согласования конфликтов.
