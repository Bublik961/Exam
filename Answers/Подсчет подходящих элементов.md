# Подсчёт подходящих элементов
Задача на подсчёт количества чисел, превышающих заданный порог.
Использует [[Цикл]] для обхода контейнера и [[Логическое выражение]] для проверки порога (`x > threshold`).
Счётчик объявляется как целочисленная переменная `int count = 0;`.
