# Сумма положительных чисел
Дан массив или `std::vector<int>`. Складываем только положительные значения.
[[Числовые типы данных]] помогают выбрать тип суммы (`int`).
[[Условный оператор]] объясняет проверку значения (`if (x > 0)`).
[[Циклы]] объясняют перебор всех элементов контейнера.
Общий термин [[Цикл]] определён в словаре.

Пример решения на C++:
```cpp
int sum = 0;
for (int x : vec) {
    if (x > 0) sum += x;
}
