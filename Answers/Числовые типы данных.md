# Числовые типы данных
В C++ для целых чисел используется `int` (а также `short`, `long`), а для чисел с плавающей точкой - `float` и `double`.
Понятие опирается на общий термин [[Тип данных]].
Пример:
```cpp
int count = 5;
double price = 9.99;
